Connect your Codemagic account

The signing keystore is already stored in Codemagic's nenva_release variable group. Do not upload it again or create a replacement key.

  1. Open Codemagic account settings and create or copy your API token.
  2. Open the Render dashboard, select the existing HiglowCloud API web service, then open Environment.
  3. Add CODEMAGIC_API_TOKEN with the token as its secret value and save the changes.
  4. Wait for the existing API service to restart, then refresh this page.

Never paste the token into this page, GitHub source code, or a chat message. Keep it only in the HiglowCloud API's Render environment.
